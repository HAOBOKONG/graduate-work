# 第七阶段系统联调与测试记录

## 1. 测试环境

- 日期：2026-10-14；Windows、Java 17、Spring Boot 3.5.7、Vue 3、Vite、PostgreSQL 16.11。
- 数据库：Docker 容器 `post-demo`，`secondhand_market`，端口 5432；Flyway 版本 2，迁移校验通过。
- 后端：默认端口 18080 已有实例响应；更新后的代码在临时端口 18081 启动并做 HTTP 检查，检查后停止。
- 前端：现有 5173 实例返回 HTTP 200；`npm run build` 通过。构建仍提示主包超过 500 kB，未影响运行。
- 集成测试设置 `RUN_DB_TESTS=true`，连接真实 PostgreSQL。测试事务回滚，不保留测试账号、商品或订单。

## 3. 测试结果

- 真实 PostgreSQL 集成测试共 **21 项，通过 21 项，失败 0 项，错误 0 项，跳过 0 项**。新增完整流程用例覆盖用户 A、管理员、用户 B 的连续操作，最终数据库中订单为 `COMPLETED`、商品为 `SOLD`，成交价格快照为 `88.50`。测试完成后事务回滚。
- 实库检查：`users` 6 行（活跃管理员 1 名、活跃普通用户 5 名）、`categories` 6 行、`products` 5 行、`orders` 2 行；测试前后数量相同。已有分类含数码电子、图书教材、生活用品，无需额外插入开发数据。
- 四张核心表的外键共 6 个、索引共 15 个；金额使用 `NUMERIC(12,2)`，订单持有商品和卖家外键及成交快照。现有结构适合当前演示规模，本阶段无需迁移。
- 后端启动日志无异常；存在 Hibernate 对显式 PostgreSQL 方言的非阻断弃用提示。前端构建存在既有包体积提示。
- 前后端原有 18080/5173 实例仍在运行；本轮更新后的后端在 18081 通过 HTTP 检查。原有 18080 实例需要重启后才会加载本轮后端改动。
