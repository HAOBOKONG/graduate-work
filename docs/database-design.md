# 数据库设计

数据库：`secondhand_market`，PostgreSQL 16，public schema。当前仅建设结构和 User Mapper，不实现交易、权限或聊天业务。

## 总体规范与设计理由

- 每表 BIGINT identity 主键，统一 created_at/updated_at TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP。触发器自动维护 updated_at，Java 使用 OffsetDateTime。
- 金额使用 NUMERIC(12,2)，Java 后续使用 BigDecimal；不使用浮点数。
- VARCHAR + CHECK 管理状态，后续扩展通过新增 Flyway 版本完成。
- 外键默认 RESTRICT，保留交易历史；后续禁用用户或下架商品，不直接物理删除历史。
- 订单保存标题和成交金额快照；禁止依赖商品当前售价。
- 商品唯一成交：部分唯一索引限制每商品仅一个非取消订单，包括已完成订单。模拟支付允许多次尝试但仅一次成功。
- 分类禁止直接自引用；多级循环、消息发送者是否为会话参与者、管理员角色校验、合法状态流转与支付金额匹配由下一阶段 Service 在事务中保证。本阶段不实现这些业务。
- BCrypt 格式 CHECK 防止普通明文写入；真正哈希必须由未来服务端密码编码器生成。禁止返回密码或记录敏感字段。
- 不预置账户、分类、商品等数据。

## 公共字段（适用于全部12张表）

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| id | BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY | 数据库生成主键 |
| created_at | TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMPTZ NOT NULL DEFAULT CURRENT_TIMESTAMP | 更新时间，由触发器维护 |

## users

用户身份；password 仅允许 BCrypt 哈希。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| username | VARCHAR(50) NOT NULL UNIQUE | 用户名 |
| password | VARCHAR(100) NOT NULL CHECK (password ~ '^\$2[aby]\$[0-9]{2}\$[./A-Za-z0-9]{53}$') | BCrypt 密码哈希 |
| nickname | VARCHAR(50) NOT NULL | 昵称 |
| avatar | VARCHAR(1024) | 头像地址 |
| phone | VARCHAR(32) | 电话 |
| email | VARCHAR(254) | 邮箱 |
| role | VARCHAR(16) NOT NULL DEFAULT 'USER' CHECK (role IN ('USER','ADMIN')) | 用户角色 |
| status | VARCHAR(16) NOT NULL DEFAULT 'ACTIVE' CHECK (status IN ('ACTIVE','DISABLED')) | 账号状态 |

额外约束：无。

## categories

支持父子分类。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| name | VARCHAR(100) NOT NULL | 分类名称 |
| parent_id | BIGINT REFERENCES categories(id) ON DELETE RESTRICT | 父分类，根分类为空 |

额外约束：CHECK (parent_id IS NULL OR parent_id <> id)。

## products

一条记录对应一件二手商品。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| seller_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 卖家 |
| category_id | BIGINT NOT NULL REFERENCES categories(id) ON DELETE RESTRICT | 分类 |
| title | VARCHAR(200) NOT NULL | 标题 |
| description | TEXT NOT NULL | 描述 |
| price | NUMERIC(12,2) NOT NULL CHECK (price > 0) | 售价 |
| original_price | NUMERIC(12,2) CHECK (original_price >= 0) | 原价，可为空 |
| condition_level | SMALLINT NOT NULL CHECK (condition_level BETWEEN 1 AND 5) | 成色 1至5：较差、一般、良好、近新、全新 |
| status | VARCHAR(32) NOT NULL DEFAULT 'PENDING_REVIEW' CHECK (status IN ('PENDING_REVIEW','ON_SALE','RESERVED','SOLD','OFF_SHELF','REJECTED')) | 商品状态 |

额外约束：UNIQUE (id, seller_id)。

## product_images

商品多图，地址而非二进制。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| product_id | BIGINT NOT NULL REFERENCES products(id) ON DELETE RESTRICT | 商品 |
| image_url | VARCHAR(1024) NOT NULL | 图片地址 |
| sort_order | INTEGER NOT NULL DEFAULT 0 CHECK (sort_order >= 0) | 图片顺序 |

额外约束：无。

## favorites

用户收藏。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| user_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 收藏者 |
| product_id | BIGINT NOT NULL REFERENCES products(id) ON DELETE RESTRICT | 商品 |

额外约束：UNIQUE (user_id, product_id)。

## orders

交易订单及不可随商品修改而变化的快照。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| order_no | VARCHAR(64) NOT NULL UNIQUE | 业务订单号 |
| buyer_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 买家 |
| seller_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 卖家 |
| product_id | BIGINT NOT NULL | 商品，复合外键校验卖家 |
| product_title_snapshot | VARCHAR(200) NOT NULL | 下单时标题 |
| price_snapshot | NUMERIC(12,2) NOT NULL CHECK (price_snapshot > 0) | 下单时价格 |
| status | VARCHAR(16) NOT NULL DEFAULT 'WAIT_PAY' CHECK (status IN ('WAIT_PAY','PAID','SHIPPED','COMPLETED','CANCELLED')) | 订单状态 |

额外约束：CHECK (buyer_id <> seller_id)；FOREIGN KEY (product_id, seller_id) REFERENCES products(id, seller_id) ON DELETE RESTRICT。

## order_events

记录订单状态变化，不执行状态流转。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| order_id | BIGINT NOT NULL REFERENCES orders(id) ON DELETE RESTRICT | 订单 |
| old_status | VARCHAR(16) CHECK (old_status IN ('WAIT_PAY','PAID','SHIPPED','COMPLETED','CANCELLED')) | 原状态；初始事件可空 |
| new_status | VARCHAR(16) NOT NULL CHECK (new_status IN ('WAIT_PAY','PAID','SHIPPED','COMPLETED','CANCELLED')) | 新状态 |
| operator_id | BIGINT REFERENCES users(id) ON DELETE RESTRICT | 操作人，系统事件可空 |
| remark | VARCHAR(500) | 备注 |

额外约束：无。

## conversations

商品买卖双方会话。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| product_id | BIGINT NOT NULL | 商品，复合外键校验卖家 |
| buyer_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 买家 |
| seller_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 卖家 |

额外约束：CHECK (buyer_id <> seller_id)；UNIQUE (product_id, buyer_id, seller_id)；FOREIGN KEY (product_id, seller_id) REFERENCES products(id, seller_id) ON DELETE RESTRICT。

## messages

会话中的文本消息。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| conversation_id | BIGINT NOT NULL REFERENCES conversations(id) ON DELETE RESTRICT | 会话 |
| sender_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 发送者 |
| content | TEXT NOT NULL CHECK (length(btrim(content)) > 0) | 非空消息内容 |
| read_status | BOOLEAN NOT NULL DEFAULT FALSE | 是否已读 |

额外约束：无。

## reports

针对商品的举报。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| reporter_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 举报人 |
| product_id | BIGINT NOT NULL REFERENCES products(id) ON DELETE RESTRICT | 商品 |
| reason | VARCHAR(1000) NOT NULL | 举报原因 |
| status | VARCHAR(16) NOT NULL DEFAULT 'PENDING' CHECK (status IN ('PENDING','RESOLVED','REJECTED')) | 待处理、已处理、已驳回 |

额外约束：无。

## payment_records

模拟支付尝试记录，不接入支付平台。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| order_id | BIGINT NOT NULL REFERENCES orders(id) ON DELETE RESTRICT | 订单 |
| payment_no | VARCHAR(64) NOT NULL UNIQUE | 模拟支付流水号 |
| amount | NUMERIC(12,2) NOT NULL CHECK (amount > 0) | 支付金额 |
| payment_status | VARCHAR(16) NOT NULL DEFAULT 'PENDING' CHECK (payment_status IN ('PENDING','SUCCESS','FAILED')) | 支付尝试状态 |

额外约束：无。

## audit_logs

管理员操作留痕。另含上述三个公共字段。

| 字段 | 类型与约束 | 说明 |
|---|---|---|
| operator_id | BIGINT NOT NULL REFERENCES users(id) ON DELETE RESTRICT | 操作人 |
| operation | VARCHAR(100) NOT NULL | 操作名称 |
| target_type | VARCHAR(50) NOT NULL | 目标类型 |
| target_id | BIGINT NOT NULL | 目标ID，跨表引用不设外键 |
| detail | TEXT | 操作详情，不存密码等秘密 |

额外约束：无。

## 索引

主键和 UNIQUE 自动创建索引，order_no/payment_no/username 不重复创建索引。收藏唯一索引覆盖 user_id 查询，会话唯一索引覆盖 product_id 查询。其他索引如下：

- `categories`：(parent_id)
- `products`：(seller_id)；(category_id)；(status, created_at DESC)
- `product_images`：(product_id, sort_order, id)
- `favorites`：(product_id)
- `orders`：(buyer_id, created_at DESC)；(seller_id, created_at DESC)
- `order_events`：(order_id, created_at, id)；(operator_id)
- `conversations`：(buyer_id, updated_at DESC)；(seller_id, updated_at DESC)
- `messages`：(conversation_id, created_at, id)；(sender_id)
- `reports`：(reporter_id)；(product_id)；(status, created_at)
- `payment_records`：(order_id)
- `audit_logs`：(operator_id, created_at DESC)；(target_type, target_id)

## 关系

用户分别关联发布商品、收藏、买卖订单、会话、发送消息、举报和管理员日志。分类自关联，并一对多关联商品。商品一对多关联图片、收藏、订单、会话和举报；订单一对多关联事件与支付记录；会话一对多关联消息。订单和会话通过商品+卖家复合外键防止卖家不匹配。audit_logs.target_id 为多态目标，不建立错误的单表外键。

## 迁移安全与运行

启动时在 FlywayMigrationStrategy 中先连接同一 PostgreSQL 的 postgres 维护库，只读检查目标库，缺失则 CREATE DATABASE secondhand_market；已有库直接复用。需要连接账号具有 CREATEDB 权限；无权限时由管理员手动创建库。DB_URL 仅接受指向 secondhand_market 的 PostgreSQL URL，防止误向 postgres 执行迁移。

Flyway 执行 V1 创建12张业务表和历史表；clean-disabled=true，baseline-on-migrate=false。已有非空 schema 未被 Flyway 纳管时拒绝启动，须检查后另行制定迁移方案。禁止修改已执行的 V1；后续使用 V2 等新文件。

配置仍从 DB_URL、DB_USERNAME、DB_PASSWORD 环境读取；启动脚本隐藏输入密码。纯单元测试不连接数据库，真实集成测试需 RUN_DB_TESTS=true 和有效数据库环境变量；测试仅对已有库进行 SELECT，不插入测试账户。
